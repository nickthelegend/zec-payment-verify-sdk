# Hanko zero-tolerance audit — Phase 1 plan

No mocks; Zcash sends are forbidden; recorded txids are read-only. Source baseline: README.md, TESTING.md, e2e/tests/*.spec.ts and the implementation named below. The baseline includes the cinematic hero commits 09c0b22 and 65ee4be (packages/landing/assets/hero.webp, .stage, hk-drift, hk-sweep). This file was transplanted from 81c6594 then extended. Phase 1 executes nothing. Phase 1 executes no servers, browsers, tests or chain requests. Later checks must preserve these wallet/key restrictions, use isolated disposable stores, and never open ~/zec-testnet-wallet, .env files, seeds, spending keys, UFVKs or print viewing keys. This repo deploys no contracts. Unexpected console errors, page errors or failed network requests fail the affected row; only the exact failure under examination is expected. All evidence remains uncollected.
