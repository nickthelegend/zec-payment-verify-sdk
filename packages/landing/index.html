zpay-verify

Was I paid?

Check an incoming shielded Zcash payment (amount, memo, confirmations, nothing transparent) with only your incoming viewing key. The same call checks a null-402 payment proof against the contracts on Avalanche Fuji.

Source Rules and API
Paid

Three lines

import { verify } from '@zpv/sdk';
const r = await verify({ rail: 'zcash', uivk, txid, amountZat: 10_000, memo: 'zpv-…' });
if (!r.ok) console.log(r.reasons);   // MEMO_MISMATCH, AMOUNT_TOO_LOW, TRANSPARENT_PART, …

Also a Rust crate and CLI (zpay-verify verify <txid> --amount --memo, exit 0 / 1 / 2), an x402 paywall that answers 402 with a memo nonce, and an MCP server so an agent checks before it delivers.

Limits

Testnet only. The checker trusts lightwalletd not to withhold transactions (it recomputes every txid). A viewing key shows every incoming payment to its wallet, so share it only with whoever should see them. A fully passing null-402 check needs null-402's pool operator to register a new root, which this project cannot do.
