Limits

Testnet only. The checker trusts lightwalletd not to withhold transactions, and recomputes every txid. A viewing key shows every incoming payment to its wallet, so share it only with whoever should see them. A fully passing null-402 check needs null-402's pool operator to register a new root, which this project cannot do. Not audited.
